# CoffeeHub — سامانه مدیریت کافی‌شاپ باشگاه

CoffeeHub یک سامانهٔ یکپارچه برای پیشخوان، صندوق فروش، مشتریان، کیف پول، محصولات، دسته‌بندی‌ها، فاکتورها، گزارش‌ها، کاربران، کارکنان و نسخهٔ پشتیبان است.

## قابلیت‌های اصلی

- ورود امن با سه سطح دسترسی: **مدیر سامانه**، **سرپرست شیفت آقایان** و **سرپرست شیفت بانوان**
- صندوق سریع با جست‌وجوی مشتری و محصول، ایجاد فوری مشتری و شارژ کیف پول
- پرداخت نقدی، کارت‌خوان، کارت‌به‌کارت و کیف پول
- ثبت تراکنشی فاکتور، موجودی کالا و کیف پول با محافظت در برابر درخواست تکراری
- مدیریت مشتریان با فیلتر جنسیت، سوابق خرید، موجودی و گردش کیف پول
- فاکتور با تاریخ و ساعت شمسی، چاپ، ذخیره PDF و ذخیره JPG
- گزارش فروش در بازهٔ زمانی با تفکیک مبلغ و تعداد فاکتور بر اساس جنسیت
- مدیریت کاربران و کارکنان فقط برای مدیر
- دریافت و بازگردانی نسخهٔ پشتیبان معتبر SQLite فقط برای مدیر

## حساب‌های اولیه

این حساب‌ها فقط هنگام ساخت دیتابیس خالی ایجاد می‌شوند:

| نقش | نام کاربری | رمز اولیه |
|---|---|---|
| مدیر سامانه | `admin` | `1234` |
| سرپرست شیفت آقایان | `men` | `1234` |
| سرپرست شیفت بانوان | `women` | `1234` |

> **ضروری:** بلافاصله پس از اولین ورود، رمز هر سه حساب را تغییر دهید. رمز `1234` فقط برای راه‌اندازی اولیه است.

## راه‌اندازی سریع در Linux

پیش‌نیازها: Python 3.11 یا جدیدتر، Node.js 20 یا جدیدتر و npm.

```bash
chmod +x scripts/*.sh
./scripts/setup-linux.sh
./scripts/run-linux.sh
```

## راه‌اندازی سریع در Windows PowerShell

PowerShell را در پوشهٔ اصلی پروژه باز کنید:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup-windows.ps1
.\scripts\run-windows.ps1
```

پس از اجرا، آدرس فرانت‌اند و API در ترمینال نمایش داده می‌شود. دیتابیس در اولین اجرا ساخته و حساب‌های اولیه seed می‌شوند.

## تغییر رمزها

### تغییر رمز مدیر

1. با حساب `admin` وارد شوید.
2. از منوی **کاربران و کارکنان** وارد زبانهٔ **تغییر رمز مدیر** شوید.
3. رمز فعلی و رمز جدید را وارد کنید.
4. بعد از تغییر موفق، دوباره وارد شوید اگر نشست جاری باطل شده باشد.

### تغییر رمز سرپرست شیفت آقایان یا بانوان

1. با مدیر وارد شوید.
2. به **کاربران و کارکنان ← کاربران سامانه** بروید.
3. کنار حساب `men` یا `women` دکمهٔ کلید/بازنشانی رمز را بزنید.
4. رمز جدید را ثبت کنید و آن را از مسیر امن به کاربر تحویل دهید.

مدیر نباید رمز حساب جاری خودش را از دکمهٔ بازنشانی کاربران تغییر دهد؛ برای حساب جاری فقط فرم **تغییر رمز مدیر** استفاده می‌شود.

راهنمای کامل‌تر: [`docs/ADMIN_GUIDE_FA.md`](docs/ADMIN_GUIDE_FA.md)

## ساخت production فرانت‌اند

```bash
cd frontend
npm ci
npm run build
```

## اجرای API در production

```bash
cd backend
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows
# .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
uvicorn main:app --host 127.0.0.1 --port 8000 --workers 1
```

برای SQLite و عملیات Restore از **یک worker** استفاده کنید. برای مقیاس چندنمونه‌ای، دیتابیس را به PostgreSQL مهاجرت دهید.

## بررسی کیفیت

```bash
./scripts/verify-linux.sh
```

گزارش اعتبارسنجی نسخه در `RELEASE_VALIDATION.md` قرار می‌گیرد.

## نکات production

- فایل `.env.example` را به `.env` کپی کنید و secretهای واقعی و طولانی بسازید.
- پوشهٔ دیتابیس و backup را روی دیسک پایدار قرار دهید و دسترسی فایل را محدود کنید.
- API را مستقیماً روی اینترنت منتشر نکنید؛ پشت reverse proxy با HTTPS اجرا کنید.
- قبل از Restore، از دیتابیس فعلی backup بگیرید و در زمان خلوتی سامانه عملیات را انجام دهید.
- فایل‌های دیتابیس، `.env`، `node_modules` و محیط مجازی داخل بستهٔ source قرار نگرفته‌اند.
