# ماتریس قابلیت‌های CoffeeHub

| حوزه | قابلیت | وضعیت مورد انتظار |
|---|---|---|
| ورود | مدیر، سرپرست آقایان، سرپرست بانوان | پیاده‌سازی و کنترل سمت سرور |
| مشتریان | CRUD، جنسیت، سوابق خرید، کیف پول | متصل به صندوق و API |
| صندوق | جست‌وجوی سریع، سبد، موجودی، چهار روش پرداخت | تراکنشی و idempotent |
| محصولات | محصول و دسته‌بندی، بارکد، موجودی | CRUD و حذف نرم |
| فاکتورها | جزئیات، تاریخ شمسی، چاپ/PDF/JPG | snapshot مالی پایدار |
| گزارش‌ها | مبلغ/تعداد روزانه و تفکیک جنسیت | بازه زمانی و چاپ/PDF |
| مدیریت | کاربران، کارکنان، تغییر رمز | فقط مدیر |
| پشتیبان | download و restore معتبر | فقط مدیر، integrity check |

نتیجهٔ دقیق build و test در `RELEASE_VALIDATION.md` ثبت شده است.
